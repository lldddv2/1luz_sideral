# 題：Dancing with the SARs（NASA Space Apps 2026，Earth Science，中至高難）

- 的：互動應用，用 NISAR SAR 數據追蹤並視覺化地表變化。
- 變類：濕地/洪泛漲縮、毀林/野火、農作型與健、土濕、冰川/海冰、震/沉降形變。
- 步：一擇研究區；二下 NISAR 免費數據（資源頁）；三可加光學影像、GIS 層為境；四互動呈現。
- 呈：變化偵測圖、時序動畫、儀表板、影像滑桿、web map、story map。
- 須論：物理驅因假說；何極化顯何變（陸、冰）；NISAR 未來用。
- 可加：多極化/多頻（他感測器）、多期時序、輔數據（人口、植被型）、人為驅因（農、工）、在地故事。
- SAR 要：主動微波；晝夜穿雲；敏於粗糙度與介電常數；水介電高，顯水體、洪、土濕；InSAR 量厘米形變。
- 終：開源、易用、可行動洞見；受眾：科學家、管理者、教育者、決策者、公眾。
