# Onboarding tour

A guided tour introduces the interface. It starts automatically on the first visit, shortly after the page loads. Restart it anytime with **Ver guía** (Show guide) on the sidebar rail.

## Steps

1. **Bienvenido a Luzsi** (Welcome to Luzsi).
2. **Buscar y fechas** (Search and dates): the search bar.
3. **Herramientas** (Tools): the sidebar rail.
4. One step per section, each opening it: **Área de estudio**, **Puntos de interés**, **Coberturas**, **Descarga**, **Modelo propio**, **Capas**, **Acerca**.
5. **Línea de tiempo** (Timeline).
6. **El mapa** (The map).
7. **¡Listo!** (Done!), pointing at the **Ver guía** button.

Use **Siguiente** (Next) and **Anterior** (Previous) to move. The last opened section stays open at the end.

```{note}
The app remembers that you saw the tour in browser local storage. If storage is blocked, the tour does not start automatically.
```
