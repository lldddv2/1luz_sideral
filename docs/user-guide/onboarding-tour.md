# Onboarding tour

A guided tour introduces the interface. It starts automatically on the first visit, shortly after the page loads. Restart it anytime with **Start tour** on the sidebar rail.

## Steps

1. **Welcome to Luzsi**.
2. **Search and dates**: the search bar.
3. **Tools**: the sidebar rail.
4. One step per section, each opening it: **Study area**, **Points of interest**, **Land cover**, **Download**, **Your model**, **Layers**, **About**.
5. **Timeline**.
6. **The map**.
7. **All set!**, pointing at the **Start tour** button.

Use **Next** and **Back** to move. The last opened section stays open at the end.

```{note}
The app remembers that you saw the tour in browser local storage. If storage is blocked, the tour does not start automatically.
```
